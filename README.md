# WebYugi
WebYugi é uma plataforma web para criação de Decks e realização de duelos online de Yu-Gi-Oh!. O projeto busca reproduzir as principais regras e mecânicas do jogo, com partidas em tempo real e um motor de regras responsável por validar as ações dos jogadores.


## Configuração local

O arquivo WebYugi/appsettings.json contém configuração de conexão local e não é versionado. Em um clone novo, copie WebYugi/appsettings.example.json para WebYugi/appsettings.json e preencha as credenciais do PostgreSQL local. Não coloque senhas reais no exemplo.
